# NOTICE

OHAR is an independent terminal AI-agent CLI. It was built after studying
[oh-my-hermes](https://github.com/rlaope/oh-my-hermes) (MIT, Copyright (c)
2026 oh-my-hermes contributors) and adapts a small amount of its MIT-licensed
material:

- Eight curated skills under `skills/`, adapted and rewritten. See
  `skills/NOTICE.md` for sources and attribution.
- Terminal presentation and interaction ideas (not wholesale code) informed by
  its TUI modules.

The upstream project is an orchestration layer for Hermes Agent; OHAR shares no
runtime code or network services with it. The root `LICENSE` is retained to
preserve the upstream MIT notice for the adapted material.

Original OHAR code is provided under the same MIT terms as this repository.
